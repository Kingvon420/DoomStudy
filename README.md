# DoomStudy
## Switchboard (new project)

A playable prototype of a "one world, every game" metaverse: walk your party between a 2K-style, Madden-style and COD-style game inside one shared city. Open `switchboard/index.html` in a browser, and read `switchboard/VISION.md` for the idea. `switchboard/roadmap.html` has the phase-by-phase build plan.
