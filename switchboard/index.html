Plug in any game

Every game in Switchboard is a cartridge that plugs into one kernel. The kernel owns the things that should never change between games: your crew, your wallet, your controls, and the world map. A game only has to describe its own rules.

KERNELparty, wallet, input, camera, portals
CARTRIDGErules, field, scoring, AI
CONTRACTenter → update → draw → finish

Register one more cartridge and a new portal appears in the plaza on the next load. That is the whole trick behind "every game in one world":

OS.register({
  id: 'kart', title: 'KART', tagline: 'Racing · 90s',
  color: '#ffd23f', zoom: 600, world: { w: 2000, h: 1200 },
  hint: 'A = boost',
  drawIcon(g, x, y, s) { /* the portal's logo */ },

  enter(ctx) {
    // ctx.party is the same crew from the plaza
    this.ctx = ctx;
  },
  update(dt) {
    // read input.x, input.y, input.act
    // when the race ends:
    // this.ctx.finish({ score, coins, summary });
  },
  draw(g)  { /* draw the track */ },
  focus()  { return this.you; },   // camera target
  status() { return 'LAP 2/3'; }
});
